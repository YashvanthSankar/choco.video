# Code of conduct

Be kind, be specific, assume good faith. Disagreement about code is normal; contempt for people is not.

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Unacceptable behaviour includes harassment, personal attacks, publishing others' private information, and sustained disruption. Report incidents to the maintainer listed in the repository profile; reports are handled privately. Maintainers may remove comments, commits or contributors that break these rules.
